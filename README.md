# Remote MCP Hosting

This repository is intended to deploy and operate remote MCP servers on Azure, including gateways to backend workers that may remain on a local Windows machine. Upstream MCP implementations will remain external and unmodified.

- `infra/` — future Azure infrastructure as code.
- `integrations/` — future per-server deployment configuration and adapters.
- `docs/` — future setup and operational documentation.

**Status:** Scaffolding only. Nothing is implemented or deployed.
